    대시보드에 등록할 Redirect URI (지금 이 주소 기준)

      현재 모드의 곡을 하나씩 Spotify 에서 찾아, 무엇에 매칭됐는지 보여줍니다. 기대한 곡과 다르면 표시되니 그것만 확인하시면 됩니다.

        다른 기기의 카메라로 찍으면 이 앱이 열리면서 Client ID 가 자동으로 채워집니다. 그 기기에서 Spotify 로그인만 따로 해주세요.

        설정 방법
        1. developer.spotify.com/dashboard 에서 Create app
        2. App name 아무거나 입력, Redirect URI 에 위 주소를 그대로 붙여넣기. 주소 끝의 /index.html 유무에 따라 값이 달라지므로, 두 형태를 모두 등록해 두면 어느 쪽으로 열어도 로그인됩니다
        3. API 선택에서 Web Playback SDK 체크 후 저장
        4. Settings 에서 Client ID 복사해 위 칸에 붙여넣기
        5. Settings → User Management 에 본인 Spotify 계정 이메일 추가 (개발 모드는 5명까지)
        6. 위 Spotify 로그인 버튼 누르기

        Spotify Premium 이 필요합니다. 모바일 전용 요금제는 SDK 재생이 되지 않습니다.
